# Rúbrica semanal (0–4 cada criterio)
- **Comprensión:** 0 no explica; 2 explica con ayuda; 4 explica y transfiere.
- **Práctica:** 0 no corre; 2 corre con guía; 4 código funcional y propio.
- **Reproducibilidad:** 0 sin archivos; 2 reproduce local; 4 rutas relativas, datos y README.
- **Interpretación:** 0 interpreta erróneamente; 2 describe; 4 contextualiza supuestos y límites.
**Umbral sugerido:** 12/16 para avanzar; si baja de 12, reforzar lo necesario.
